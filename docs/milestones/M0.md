
Result: CMake configure and GCC build passed; all 3/3 CTest cases passed; normal
runs exited 0; the deliberately missing config exited 1 as expected; the board
collector passed POSIX shell syntax checking but was not run on a board.

`--version`, and `--config <path>`. It reads the selected file to completion but
does not interpret operational settings.
