## 实现范围

### 配置、日志和错误

配置语法为逐行 `key=value`，支持空行和行首 `#` 注释。未知 key、同一文件重复 key、
缺少 `=`、非法字符和越界数值都会返回稳定错误码。合并优先级固定为内建默认值、配置
文件、按出现顺序应用的 `--set KEY=VALUE`。解析或校验过程不会连接任何外部服务。

| key | 默认值/状态 | M1 校验边界 |
| --- | --- | --- |
| `device_id` | `gateway-lab` | 1～63 字节，`[A-Za-z0-9._-]` |
| `can_interface` | `can0` | 1～15 字节的接口名字符 |
| `broker_host` | `broker.example.invalid` | 1～255 字节，不含空白/控制字符 |
| `broker_port` | `1883` | 1～65535 |
| `broker_username` / `broker_password` | 空 | 分别最多 127/255 字节；日志始终脱敏 |
| `mqtt_topic` | `vehicle/gateway-lab/telemetry` | 1～255 字节；发布 topic 禁止 `+`/`#` |
| `queue_capacity` | `1024` | 1～65536 |
| `queue_push_timeout_ms` | `50` | 0～60000 ms |
| `batch_interval_ms` | `1000` | 100～60000 ms |
| `spool_path` | `/var/lib/gatewayd/spool.data` | 绝对路径；M1 不创建或写入该文件 |
| `log_level` | `info` | `debug/info/warn/error` |

日志使用 UTC 毫秒时间戳、等级和 component，并由 mutex 保证单条日志不在线程间交错。
配置摘要将 Broker username/password 输出为 `<redacted>`/`<unset>`，测试用假密码未出现
在日志中。错误码在 `gateway/error.h` 冻结为 `OK`、argument/I/O/parse/unknown key、
duplicate key、range、invalid value、timeout、closed 和 system error。

### 生命周期、stats 和记录布局

`SIGINT`/`SIGTERM` handler 只执行 async-signal-safe 的 nonblocking pipe `write()`；
普通线程通过 `poll()` 接收后设置 stop 状态并 broadcast。条件等待使用 `while` 谓词，
支持确定性 request-stop 唤醒和 timeout。64-bit stats 全部在 mutex 下访问，不假设 ARMv7
的 64-bit 原子操作 lock-free。

`telemetry_record` 使用定宽整数并由 `_Static_assert` 冻结为 64 字节：

| offset | 字段 | 大小 |
| ---: | --- | ---: |
| 0 | `gateway_seq` | 8 |
| 8 | `kernel_timestamp_ns` | 8 |
| 16 | `can_id` | 4 |
| 20 | `data` | 8 |
| 28 | `status_flags` | 2 |
| 30 | `dlc` | 1 |
| 31 | `ecu_counter` | 1 |
| 32 | `decoded_payload` | 32 |

最后 32 字节只是布局预留。M1 没有实现 DBC 或声明解码信号语义；该工作仍属于 M4。

### 有界环形缓冲区

队列维护 capacity/head/tail/count/closed，使用 mutex、`not_empty` 和 `not_full` 条件变量。
producer 在满队列上使用基于 `CLOCK_MONOTONIC` 的单一绝对 deadline 有界等待；timeout
返回给调用方，由后续真实链路执行“丢弃新记录”。close 会 broadcast 所有 waiter；
consumer 可先 drain close 前已有记录，只有 closed 且 empty 才返回 `CLOSED`。统计覆盖
push attempt/success/timeout/closed、pop success/closed 和 high-watermark。
